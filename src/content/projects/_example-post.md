This is a placeholder post — delete it once you've added a real one. It exists
so the `projects` content collection has at least one file to validate its
schema against.

Frontmatter fields:

- `title` — display title for the grid tile and the post page
- `date` — publish date, used for sorting
- `tags` — category strings (e.g. `work`, `learning`, `music`, `travel`, `thoughts`) — this is how work/learning/personal posts get differentiated instead of separate pages
- `cover` — optional cover image, relative to this file (e.g. `./cover.jpg`)
- `summary` — one or two sentence teaser shown on the grid tile
- `draft` — set to `true` to keep a post out of the grid once it's wired up
